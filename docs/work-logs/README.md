# Work logs

One file per topic per day: `YYYY-MM-DD-<topic>.md`. A day with three unrelated tasks has three files.

```markdown
---
type: work-log
date: 2026-11-11
status: "One line: where this stands today."
title: "…"
tags: [...]
---
```

Sections, short: **Asked** (the request, in a line or two), **Decided**, **Done** (with commits), **Checked** (what was verified and how), **Open** (what is left, and who acts).

Facts that outlive the task go to `architecture/`, `runbooks/` or `decisions/` the same day; the log links to them instead of repeating them. This repo is public: no account ids, pool ids, emails, tokens or secret values, ever.
