One key to schedule: @

Type @ at the start of a word anywhere you write: a task description, a note, a list item, a table cell. A date picker opens right there; Enter turns what you typed into a date chip and an event.

• Book the renewal appointment Sun 15 Nov · 10:00 event title = the line’s text

Why @, and not the others

KeyWhat it already does in your textVerdict
@ word startAn email has a letter before its @ (mir@gmail.com), so it never opens the picker. Only a space or the line start before @ does.Use it
## at a line start is already Heading 1 (Markdown shortcut), and # is the natural key for tags later.No
//Every link has https://, and code blocks have // comments.No
!Ends sentences (“Done!”), so it would pop up all the time.No

Keys and clicks

↑ ↓Choose a suggestion
EnterInsert the chip, create the event
EscClose; what you typed stays as plain text
BackspaceRight after a chip removes it; ⌘Z brings it back
Click a chipChange day or time, mark done, keep the text out of the calendar, remove
Toolbar“Schedule” button types the @ for you; with words selected, they become the event title
The Agenda replaces today’s “Due today or late” list in the Library. It shows both kinds of dates: the chips you type and the task due dates you already set. Times are stored with your time zone (Asia/Dhaka), so the calendar shows the same hour on every device.
